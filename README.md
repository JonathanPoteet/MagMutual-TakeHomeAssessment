# MagMutual-TakeHomeAssessment


## Requirements
In the accompanying CSV file, you will find a list of Users. We want you to build a simple microservice that exposes a couple endpoints and a frontend to display the returned information.

Tech Stack:

· The microservice has been built using Java Spring Boot

· The frontend has been built using ReactJS in Typescript

Base features:

· Endpoint to return all users

· Endpoint to return a specific user

· User information displayed on the frontend in a visually appealing way

Optional features (choose at least 2 of the 4):

1. Ability to create and delete users

2. Ability to filter, sort, and search users

3. Create a custom endpoint of your own to transform or visualize the data in a different way. This should also include a corresponding frontend component/display.

4. Create an ERD that shows how you would go about accommodating the following user request:

1. Request: HR needs to associate users with various Companies. Can you model what the data would look like?

2. We know a Company will need the following information:

- 1. name

- 2. location

- 3. phone number

- 4. email

- 5. employees

Deliverables:

· A link to the source code and any additional artifacts. Please send this over at least 24hrs prior to next interview round.

· Be prepared to demo & discuss your work
